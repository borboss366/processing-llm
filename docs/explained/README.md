# The explain-it gate (brief 19.2)

One file per feature, written BY THE OWNER — a paragraph in his own
words: what it does and how. If the paragraph can't be written, the
feature waits outside the party set. Claude Code asks for the
paragraph when a feature is proposed for the set and refuses the
merge without it; it never writes these files.

## Facts behind the verdicts (no fixes made in this session)

- **Body roll "still jumps".** The table is not the cause any more:
  before, 5 of 13 keys had NO foot planted (0.30–0.64); now all 14 keys
  plant a foot (both on 12, the left only at 0.66–0.72, weight −0.95).
  The feet still leave the floor on stage, so the lift comes from the
  root, not from the contacts: for a captured table the stance lock
  holds height only and yields when the table's own FK lifts the foot;
  a body roll raises the root, so both feet go up with it. That is the
  case Task 2.1 targets (the root solved FROM the support foot, the feet
  no longer pulled to the floor under a floating root). Re-judge after
  Task 2; if it still jumps, it becomes a numbered finding.
- **Running man front "static", should bob.** No root motion from the
  weight yet; Task 2.4 (sink on transfer) is the up-and-down step.
- **T-step "tilt changes immediately".** The weight in the table rocks
  −0.97 → +1 within a few keys; Task 2 must blend the pelvis tilt
  through zero (the brief's "no pop" requirement) — this verdict makes
  it a check for the Task 2 stress row (transition rate, not only
  continuity).
- **Explorer: S5 limits, foot.** Consistent with the earlier clamp
  finding on captured feet (tstep footL/footR whitelisted, 22/24 in-window
  hits). Owner located the stage from the explorer alone.

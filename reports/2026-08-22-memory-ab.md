## Judgment (facts from the table only)

- On every counted metric the variants tie. The zero-revisit result in BOTH
  columns is produced by the recency blocklist (12), which excludes recent
  slugs from the candidate list mechanically — the memory block never gets
  the chance to prevent a repeat, because the prefilter already did.
- Memory costs ~1.6 s extra per pick (+35%) and ~380 extra prompt tokens —
  the history lines in the tail are re-evaluated every call.
- Whether either sequence "reads as a progression" is not visible in preset
  names; that aesthetic judgment is the operator's, from watching a set.

**Default changed to `no-memory`** (`DEFAULT_PROMPT_VARIANT` in
`director.ts`): measurably equal on diversity/holds/validity, measurably
cheaper and faster. The memory variant remains selectable
(`--prompt-variant memory` in replay; `variant` field on `/director`) —
replay A/B stays possible, and the call can be revisited if a longer
session or a listening test shows a progression effect the table cannot.

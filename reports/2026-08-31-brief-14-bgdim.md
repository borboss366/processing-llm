## Design

- `FS_COMPOSITE` gains `uBgDim`: the background sample steps to
  brightness ×0.45 / saturation ×0.7 at full weight
  (`mix(col, mix(vec3(luma), col, 0.7) * 0.45, uBgDim)`).
- The weight is the creature's OWN composite fade envelope
  (lifecycle alpha × entry env × swap env), exposed as a timestamped
  read-only seam (`window.__creatureAlpha`) from the creature's draw —
  so the dim eases exactly with the figure's entry/exit fades, including
  the audience-shape hot-swap dip. No new easing logic.
- Staleness guard: a seam older than 1.2 s reads as weight 0, so the
  background always restores when drawing stops (unload, disable,
  panic); teardown also zeroes the seam explicitly. The guard was
  originally 250 ms — headless/software rendering draws as slowly as
  ~3 fps (measured 260–410 ms frame gaps), which made the dim flicker
  off in harness runs.
- Param `bgDim` (default **on**, per brief); `/post/bgDim 0` disables.
  In the DOM-bypass path (post 0) there is no dim — compositor-native by
  design, and post is on by default (gate B3 verdict).

## Acceptance (tools/bgdim-check.mjs, verify --full row "bgdim")

Bright preset (the measured brightness-5 "Why The Sky Looks Diffrent
Today") over the gridded mix, creature idling at centre. The probe reads
the corner strips of the COMPOSITE and the raw #bg canvas in the same
rAF and uses the comp/bg ratio — the preset's audio-reactive luminance
swings (which broke naive A/B windows, cycle ratios 0.50–1.45) cancel
exactly; only the pipeline's own attenuation remains.

| measure | value | gate |
|---|---|---|
| step-down, dim vs undim comp/bg factor (3 cycles) | 0.47 / 0.48 / 0.49 (median **0.48**) | ≤ 0.75 |
| restore after creature exit (through the 900 ms fade) | **1.02** of undimmed | ≥ 0.8 |
| undimmed comp/bg factor (vignette + knee baseline) | 0.88 | — |

The measured 0.48 sits exactly on the design value (×0.45 brightness,
with the ×0.7 desaturation's small luma effect). Stills:
`reports/bgdim-on.png` / `bgdim-off.png`.

Frame budget: one extra uniform + 3 shader ops in the composite pass —
no new passes, no readbacks in the live path.
